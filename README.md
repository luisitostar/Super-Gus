# 🛒 SÚPER GUS
### Sistema de Gestión Empresarial

Sistema desarrollado en Python para facilitar la administración de un negocio local.

## 🎯 Objetivo
Digitalizar y mejorar el control de las operaciones comerciales mediante una aplicación de gestión.

## 🚀 Funcionalidades
- 📦 Gestión de productos e inventario.
- 🛒 Registro de ventas.
- 📊 Control de ingresos.
- 📜 Historial de ventas.
- 🧾 Generación de tickets.
- ⚠️ Alertas de stock bajo.
- 💳 Control de créditos y abonos.

## 🛠️ Tecnologías utilizadas
- Python
- Streamlit
- SQLite
- Pandas

## 📁 Estructura del proyecto
- `supercre.py`: aplicación principal.
- `launcher.py`: iniciador de la aplicación.
- `requirements.txt`: dependencias necesarias.
- `SuperGus.spec`: configuración de PyInstaller.

## 👨‍💻 Proyecto académico
Desarrollado como propuesta tecnológica para apoyar la administración de un negocio local.
